# Historique des versions

Chaque version du site est envoyée sur GitHub avec une étiquette (par exemple `v1.0.0`). Sur la page du dépôt, l'onglet « Tags » permet de télécharger n'importe quelle version en ZIP.

- Le chiffre du milieu augmente pour de nouvelles fonctionnalités (v1.1.0, v1.2.0…).
- Le dernier chiffre augmente pour de petites corrections (v1.0.1, v1.0.2…).
